# 叭叭車 Beep Cars

給 18 個月大、最愛玩具車的小小孩的車車遊戲。孩子**不用碰螢幕、也不用碰鍵盤**：他站在筆電前面，用揮手、跳一跳、拍拍手這些大動作，讓畫面上的車車開動、按喇叭、跳起來。爸爸媽媽在旁邊陪著一起玩。

A car game for an 18-month-old who loves toy cars. He **never touches the screen or the keyboard**: he stands in front of the laptop and makes the cars drive, honk and jump with big movements — waving, jumping, clapping. A parent plays along.

- 單一檔案、完全離線：`dist/index.html`，不連網路、不下載任何東西。
- One self-contained file, fully offline: `dist/index.html`. No network, no downloads, no ads, no links.

## 怎麼玩 · How to play

| 孩子做什麼 · He does | 畫面發生什麼 · What happens |
| --- | --- |
| 全身動來動去 · moves his whole body | 車車開動，動越多開越快 · the car drives — the more he moves, the faster |
| 把手舉高、揮手 · arms up, waving | 叭叭！車車按喇叭、跳起來 · beep beep! the car honks and hops |
| 在左邊或右邊動 · moves on the left or right | 車車轉向那一邊 · the car turns towards that side |
| 拍手、大叫 · claps or shouts | 「嘟嘟！」加上滿天彩帶 · "doot doot!" and confetti |
| 跑開一陣子 · wanders off for a while | 一台車探頭「叭？」邀他回來 · a car peeks in and asks "beep?" |
| 亂敲鍵盤 · bangs the keyboard | 每一下都是喇叭，但永遠不會離開遊戲 · every bang is a honk, and nothing ever leaves the game |

沒有分數、沒有輸贏、沒有倒數、孩子不需要看任何字。動作到反應在 100 毫秒內。
No score, no failing, no timer pressure, no words he has to read. Movement to reaction within 100 ms.

### 四個場景 · Four scenes (the parent switches them)

1. **馬路 Road** — 車車在路上開，他動越多開越快；開夠了就叭一聲說再見，下一台車開進來。
   Cars drive along; the more he moves the faster they go. After a good drive the car honks goodbye and the next one arrives.
2. **車庫躲貓貓 Garage peekaboo** — 三間車庫。他一動，車庫門就捲起來（先看到輪子！），門開了車車就「叭！」跳出來。在哪一邊動，就開哪一間。
   Three garages. Moving rolls a door up (the wheels peek out first!); when it's open the car pops out with a honk. The side he moves on picks the garage.
3. **洗車 Car wash** — 髒兮兮的車車停在大刷子中間，他一動就冒泡泡、把泥巴洗掉；洗乾淨了閃閃發亮、開心按喇叭。
   A muddy car waits between big brushes; his movement makes bubbles and washes the mud off. Clean → sparkles and a happy honk.
4. **紅綠燈 Traffic light** — 車車在紅燈前排隊。他一動就變綠燈，所有車一起出發；完全不需要抓時機。
   Cars queue at a red light. Whenever he moves it turns green and everyone goes. No timing needed, ever.

十台車 · Ten cars: 消防車 fire engine · 警車 police car · 校車 school bus · 砂石車 dump truck · 拖拉機 tractor · 賽車 race car · 計程車 taxi · 冰淇淋車 ice-cream van · 垃圾車 garbage truck · 挖土機 digger。每台都有自己的樣子、引擎聲和喇叭聲（消防車和警車有警笛、冰淇淋車有鈴鐺、挖土機會「嗶嗶嗶」倒車），會眨眼、會笑、輪子會轉、會冒小煙、跳起來會有 Q 彈的壓扁拉長。
Each has its own look, engine hum and horn (sirens for the fire engine and police car, a bell for the ice-cream van, a reversing beeper for the digger), blinking headlight eyes, a smile, spinning wheels, little exhaust puffs and squash-and-stretch hops.

時間到了（預設 5 分鐘）：天色慢慢變暗，車車一台一台開回車庫，門關上、打起呼嚕，播放搖籃曲，**攝影機和麥克風立刻關閉**。
When the session ends (5 minutes by default) the sky slowly turns to night, the cars drive home one by one, the doors roll down, a lullaby plays, and **the camera and microphone are switched off right away**.

## 家長操作 · For the parent

1. 按 **開始 Start**。Chrome 會先問攝影機、再問麥克風，請選「允許」。沒有麥克風也能玩；沒有攝影機也能用鍵盤玩。
   Press **Start**. Chrome asks for the camera, then the microphone — choose Allow. It works without a mic; without a camera the keyboard still plays.
2. 校正：請孩子（或你自己）站到 1–2 公尺外、**保持不動 3 秒**。他亂動也沒關係，最多重來三次就會直接開始。
   Calibration: stand 1–2 m back and **stay still for 3 s**. If he can't, it retries at most three times and then just starts.
3. 開始玩。右下角的小鏡子讓他看到自己在動，外框會隨動作發亮。
   Play. The small mirror in the corner lets him see himself; its border glows when he moves.

### 家長選單 · Parent menu

**同時按住左右兩個 Shift 鍵 2 秒**（或用觸控板按住畫面左上角 2 秒）。孩子亂敲鍵盤幾乎不可能剛好只按住這兩個鍵這麼久。
**Hold both Shift keys for 2 seconds** (or press and hold the top-left corner with the trackpad). A toddler mashing the keyboard almost never holds exactly those two keys that long.

選單裡可以：換場景、調靈敏度（低/中/高）、音量、靜音、顯示/隱藏小鏡子、每次玩多久（3/5/10/15 分鐘）、重新校正、結束（車車去睡覺）。選單打開時時間暫停。按 Esc 或「繼續玩」關閉。設定只記在這台電腦的瀏覽器裡。
In the menu: switch scene, sensitivity (low/medium/high), volume, mute, show/hide the mirror, session length (3/5/10/15 min), recalibrate, end the session. The session clock pauses while the menu is open. Esc or Resume closes it. Settings are remembered in this browser only.

## 啟動（macOS + Chrome）· Launch (macOS + Chrome)

```sh
npm ci
npm run build          # → dist/index.html（單一檔案 single self-contained file）
npm start              # → http://127.0.0.1:4178/ （只在本機 localhost only）
```

### Kiosk 模式（建議）· Kiosk mode (recommended)

另開一個終端機 · In a second terminal:

```sh
open -na "Google Chrome" --args \
  --kiosk \
  --user-data-dir="$HOME/.beep-cars-chrome" \
  --app=http://127.0.0.1:4178/
```

- `--kiosk`：全螢幕、沒有網址列和分頁，孩子點不到其他東西。Full screen, no address bar or tabs.
- `--user-data-dir`：用一個獨立的 Chrome 設定檔，就算 Chrome 已經開著，這些參數也會生效；攝影機權限在這個設定檔裡只要允許一次。A separate profile so the flags apply even if Chrome is already running, and the camera permission is remembered after the first time.
- 用 `http://127.0.0.1` 而不是 `file://`：Chrome 會記住 localhost 的攝影機權限；`file://` 每次都會再問。
  Prefer `http://127.0.0.1` over `file://`: Chrome remembers camera permission for localhost, while `file://` asks every time. `file://` does work too:
  `open -na "Google Chrome" --args --kiosk --user-data-dir="$HOME/.beep-cars-chrome" --app="file://$PWD/dist/index.html"`
- 離開 kiosk：**⌘Q**。Leave kiosk mode with **⌘Q**.

**網頁擋不住的按鍵 · What a web page cannot block.** 頁面本身會：要求全螢幕、在全螢幕時鎖定鍵盤（Keyboard Lock：要按住 Esc 才能離開全螢幕）、擋掉右鍵選單、縮放、捲動、拖曳和「上一頁」手勢，並把每個按鍵變成喇叭聲。但 **⌘Q、⌘Tab、⌘H、⌘M、⌘空白鍵** 這些是 macOS／Chrome 自己的快速鍵，任何網頁都擋不住——這就是為什麼要用 kiosk 模式。想再保險一點：系統設定 → 鍵盤 → 鍵盤快速鍵 → App 快速鍵，替 Google Chrome 的「結束 Google Chrome」指定一個很難按到的組合（例如 ⌃⌥⇧⌘Q），⌘Q 就不會再關掉遊戲。
The page requests full screen, locks the keyboard while in full screen (Keyboard Lock: Esc must be *held* to leave), blocks the context menu, zoom, scrolling, dragging and the back-swipe, and turns every key into a honk. But **⌘Q, ⌘Tab, ⌘H, ⌘M, ⌘Space** belong to macOS/Chrome and no web page can block them — that's why kiosk mode. For extra safety: System Settings → Keyboard → Keyboard Shortcuts → App Shortcuts, add "Quit Google Chrome" for Google Chrome with an awkward combo such as ⌃⌥⇧⌘Q; then ⌘Q no longer quits.

## 隱私 · Privacy

- 攝影機畫面在記憶體裡縮成 64×48 的灰階小圖，只拿來算「動了多少」，算完就丟掉。**不錄影、不拍照、不儲存、不上傳。**
  Camera frames are shrunk in memory to a 64×48 grayscale image, used only to measure how much he moves, and discarded. **Nothing is recorded, photographed, stored or uploaded.**
- 麥克風只量「多大聲」（音量），不錄音、不辨識語音，也不會從喇叭播出。
  The microphone only measures loudness. No recording, no speech recognition, never played back.
- 頁面**完全不發出任何網路請求**：沒有字型、圖片、分析工具、廣告或連結。建置出來的 `index.html` 內建 Content-Security-Policy（`default-src 'none'; connect-src 'none'` …），就算程式想連網路，瀏覽器也會擋下。測試會檢查整個遊戲過程中只有頁面本身這一個請求。
  The page makes **no network requests at all**: no fonts, images, analytics, ads or links. The built `index.html` carries a Content-Security-Policy (`default-src 'none'; connect-src 'none'` …) so the browser would block any attempt. The tests assert that a whole session makes exactly one request: the page itself.
- 時間到或按「結束」時，攝影機和麥克風立刻真的關掉（Mac 的綠燈會熄滅）。
  When the session ends the camera and microphone tracks are stopped for real (the Mac's green camera light goes off).
- 只有家長的設定（場景、音量…）存在這個瀏覽器的 localStorage。
  Only the parent's settings (scene, volume…) are kept, in this browser's localStorage.

## 安全 · Safety

- 音量有上限：不管滑桿拉多高，總輸出都被限制，再經過一個限幅器。 Volume is hard-capped and runs through a limiter.
- 不閃爍：任何會閃的東西（警笛燈、星星、亮晶晶）都不超過每秒 2 次，低於光敏性癲癇建議的每秒 3 次上限；沒有全螢幕閃光。
  No flashing: anything that blinks (siren lights, stars, sparkles) stays at or under 2 Hz, below the 3-per-second photosensitivity limit; no full-screen flashes.
- 尊重「減少動態效果」(prefers-reduced-motion)：跳得比較低、彩帶和泡泡比較少、不傾斜。 Respects prefers-reduced-motion: smaller hops, fewer particles, less tilt.
- 高對比、粗外框、大物件；孩子要看的東西都沒有文字。 High contrast, thick outlines, big shapes; nothing the child needs is text.

## 為什麼這樣設計 · Design rationale for toddlers

- **因果要立刻看得到。** 18 個月大的孩子正在學「我做了什麼 → 發生了什麼」。反應延遲超過約 100 毫秒，他就連不起來了，所以偵測直接在每一格攝影機畫面上做，喇叭和跳躍在同一格就發生。
  **Cause and effect must be immediate.** At 18 months he is learning "I did that!". Beyond ~100 ms the link breaks, so detection runs on every camera frame and the honk/hop happens in the same frame.
- **大動作，不是精細動作。** 他還沒有精細的手指控制，也不會讀字。只用「整體動多少」「上面動」「左邊/右邊動」這種粗略的訊號，而且非常寬容。
  **Gross motor, not fine motor.** No fine finger control yet and no reading. Only coarse signals — how much, up high, left or right — and all of them forgiving.
- **沒有失敗。** 沒有分數、倒數或「錯了」。紅綠燈不需要抓時機；車庫門他停下來也只會慢慢往下一點點；校正就算他一直動也會開始。
  **No failure states.** No score, countdown or "wrong". The traffic light needs no timing; a garage door only sinks slowly when he pauses; calibration starts even if he never stands still.
- **躲貓貓和物體恆存。** 這個年紀正著迷於「東西藏起來還在不在」。車庫門慢慢捲起、先看到輪子、再「叭！」跳出來，就是在玩這個。
  **Peekaboo and object permanence.** Hidden-then-revealed is endlessly delightful at this age: the door rolls up, the wheels peek out, then "beep!".
- **重複又有一點點變化。** 同一個動作永遠得到同一種回應，但每次出來的車不一樣（十台車輪流，不會連續兩次一樣）。
  **Repetition with a little variety.** The same action always gets the same kind of response, but a different car each time (ten cars, never the same one twice in a row).
- **孩子跑開時溫柔邀請。** 一陣子沒動作，會有一台車探頭問「叭？」，不是警報、不是催促。
  **Gentle invitation, not nagging.** If he wanders off, a car peeks in and asks "beep?".
- **溫和的結束。** 不是突然黑掉，而是天黑、車車回家睡覺、搖籃曲——一個他看得懂的結束儀式。
  **A gentle ending ritual** he can understand: night falls, the cars go home to sleep, a lullaby.

### 關於螢幕時間 · A gentle note on screen time

美國兒科學會（AAP）建議：18 個月以下除了視訊通話外盡量避免螢幕；18–24 個月如果要接觸數位媒體，選擇高品質的內容、**由大人陪著一起看、一起玩**，並且時間要短。叭叭車就是照這個方向設計的：家長啟動、家長陪玩、預設每次 5 分鐘、有明確的結束。最好的玩法是你也一起揮手、一起叭叭叫。
The American Academy of Pediatrics suggests avoiding screens other than video chat before 18 months, and, for 18–24 months, choosing high-quality content and **co-viewing / co-playing with an adult**, in short sessions. Beep Cars is built for exactly that: the parent starts it, plays along, sessions default to 5 minutes, and the ending is clear. It's best when you wave and go "beep beep!" too.

## 開發 · Development

```
src/
  index.html, styles.css
  js/
    main.js        app shell: start → calibrate → play → sleep, parent menu, keyboard guard
    motion.js      frame-differencing motion detector (pure)
    synth.js       deterministic synthetic camera for tests (pure)
    loudness.js    clap/shout detector that ignores the game's own sounds (pure)
    session.js     session clock (pure)     keys.js   parent key combo (pure)
    audio.js       all sounds, synthesized with WebAudio
    sources.js     camera + mic → 64×48 grayscale / loudness, in memory only
    cars.js        the ten hand-drawn cars     actor.js  squash, stretch, hop, blink, puffs
    fx.js          confetti, bubbles, sparkles, puffs     backdrop.js  sky, hills, road
    scenes/        road, garage, wash, light, sleep, gallery (?scene=gallery: all cars)
scripts/build.mjs  esbuild bundle → one dist/index.html with CSP
scripts/serve.mjs  tiny localhost server (no dependencies)
scripts/proofs.mjs screenshots of every scene and car → proofs/
```

**動作偵測 · Motion detection.** 每一格新的攝影機畫面鏡像後縮成 64×48 灰階，切成 16×12 格。先用整張畫面做穩健的線性擬合（cur ≈ a·prev + b）抵銷燈光閃爍和自動曝光，再算每一格的殘差；每格有自己會自動調整的雜訊基準（校正時先學好），而且要有相鄰格一起動才算數，單一雜訊點不會觸發。整體 → 速度，上面三分之一 → 喇叭，左右 → 方向。沒有機器學習模型，也不下載任何東西。
Each new camera frame is mirrored, shrunk to 64×48 grayscale and split into a 16×12 grid. A robust whole-frame fit (cur ≈ a·prev + b) cancels flicker and auto-exposure; each cell has its own adaptive noise baseline (seeded by calibration) and only counts when a neighbour moves too. Whole frame → speed, top third → honk, left/right → steering. No ML models, no downloads.

```sh
npm test            # unit tests (node --test) + browser tests (Playwright, Chromium)
npm run test:unit
npm run test:e2e    # builds first; fake camera/mic + a synthetic motion source
npm run proofs      # screenshots → proofs/
```

瀏覽器測試用 Chromium 的假攝影機/麥克風（`--use-fake-device-for-media-stream --use-fake-ui-for-media-stream`），並用 `?synthetic` 換成可重現的合成動作來源，所以結果是確定的。
Browser tests run Chromium with a fake camera/mic and, via `?synthetic`, a deterministic synthetic motion source.

測試用網址參數 · Test URL parameters: `?synthetic` · `sessionSeconds=N` · `calibSeconds=N` · `idleSeconds=N` · `scene=road|garage|wash|light|gallery`.

CI：`.github/workflows/ci.yml` 只有一個叫 `ci` 的 job（安裝、裝 Chromium、建置、跑全部測試），可以直接設成必要檢查。
CI: `.github/workflows/ci.yml` has a single job named `ci` (install, Chromium, build, all tests), ready to be a required check.
